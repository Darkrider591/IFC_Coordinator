# IFC Coordinator — Утилита пакетной координации моделей IFC

Легковесное приложение для точного смещения (переноса) и поворота моделей IFC без повреждения геометрии, атрибутов, свойств и структуры файла. 
Разработано на базе алгоритма трансформации корневых размещений (`IfcLocalPlacement`) и библиотеки **IfcOpenShell** в корпоративной стилистике **ЦТИП**.

## 🎨 Обновленный дизайн и цветовая палитра ЦТИП

Приложение поддерживает переключение между **тёмной** и **светлой** темами в один клик:
- **Кнопка переключения темы**: расположена в верхней панели (`☀️ Светлая тема` / `🌙 Тёмная тема`).
- **Корпоративная палитра ЦТИП (4 акцентных цвета)**:
  1. **Изумрудный зелёный (`#1faa79` / `#146a4b`)**: акцентные кнопки, активные вкладки, индикаторы успеха, фокусные рамки.
  2. **Золотисто-янтарный (`#d8ce78` / `#c4b538`)**: предупреждения, вспомогательные переключатели.
  3. **Ягодно-розовый (`#e3abce` / `#953270`)**: статусная индикация и бейджи.
  4. **Благородный графит/серый (`#b1b1b0` / `#595959`)**: сетки, границы и нейтральные элементы.

## 🚀 Основные возможности

1. **Интуитивная зона Drag-and-Drop**:
   - Специальная интерактивная зона для перетаскивания файлов прямо из проводника.
   - Поддерживает как одиночные файлы `.ifc`, так и целые папки/списки файлов.
   - При клике на зону открывается стандартный диалог выбора файлов.

2. **Автоматический расчёт адреса сохранения и маска с суффиксом**:
   - При выборе или перетаскивании исходного файла **автоматически формируется и отображается итоговый путь сохранения**.
   - Доступен выбор суффикса (по умолчанию `_coordination`):
     - Например: `модель.ifc` $\rightarrow$ `модель_coordination.ifc`.
     - Суффикс настраивается пользователем как в одиночном, так и в пакетном режиме.
   - Также доступны режимы: выбор произвольного пути вручную или перезапись с созданием резервной копии (`.bak`).

3. **100% сохранность данных модели (Zero Data Loss)**:
   - Не перестраивает геометрию (BRep, Extrusion, CSG, FacetedBrep остаются нетронутыми).
   - Не изменяет и не генерирует заново идентификаторы GUID (`GlobalId`).
   - Сохраняет все наборы свойств (`IfcPropertySet`), количества (`IfcElementQuantity`), материалы, типы и связи.
   - Трансформация применяется исключительно к корневым системам координат (`IfcLocalPlacement`), благодаря чему дочерние элементы автоматически и без погрешностей занимают нужное положение в пространстве.

4. **Пакетная обработка (Batch Coordination)**:
   - Добавление множества файлов или папок.
   - Информативная таблица со схемами, единицами измерения, прогрессом и статусами.
   - Гибкие сценарии пакетного сохранения (суффикс, отдельная папка, перезапись с `.bak`).

5. **Менеджер пресетов (Presets)**:
   - Сохранение и загрузка настроек координат для разных площадок и корпусов.
   - Быстрое переключение пресетов в один клик.

## 📦 Запуск приложения

### 1. Готовый исполняемый файл (.exe)
```text
dist/IFC_Coordinator.exe
```
Запуск двойным кликом (или через `run_gui.bat`). Не требует наличия Python на компьютере.

### 2. Запуск через исходный код Python
```bash
python main.py
```

### 3. Режим командной строки (CLI)
```bash
IFC_Coordinator.exe --cli -i "input.ifc" -o "output.ifc" -x 4151394 -y -4065338 -z 184000 --az -48.55611111
```
Параметры:
- `-i`, `--input`: Путь к исходному файлу IFC.
- `-o`, `--output`: Путь для сохранения результата.
- `-x`, `-y`, `-z`: Смещения в проектных единицах.
- `--ax`, `--ay`, `--az`: Углы поворота в градусах (`--az` — угол в плане).
- `--translate-first`: Сначала сместить, затем повернуть (по умолчанию сначала поворот).
- `--no-backup`: Не создавать копию `.bak` при перезаписи.
